If you add different photos, update the corresponding -photos.json file.

HOW IT WORKS:
=============
1. Each country page (spain.html, portugal.html, etc.) loads the corresponding JSON file
2. The JSON file contains paths to photos in the photos/[country]/ folder
3. JavaScript automatically loads all photos from the JSON and displays them
4. You can add/remove photos by just updating the JSON file - no HTML changes needed!

TROUBLESHOOTING:
================
- Photos not showing? Check the filename matches exactly in the JSON file
- Folders not showing? Make sure you uploaded the .gitkeep files
- Colors/styling wrong? Check that all CSS is loading (it's inline in the HTML)
